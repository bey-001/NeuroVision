# NeuroVision
3D brain MRI lesion segmentation using FCM-enhanced UNet architecture for Multiple Sclerosis detection.

NeuroVision is a hybrid deep learning framework for **Multiple Sclerosis (MS) lesion segmentation** in brain MRI images.  
The model combines **Fuzzy C-Means (FCM)** clustering with a **3D UNet architecture** to improve segmentation performance.

---

## 🚀 Project Overview

- 📌 Task: Brain MRI lesion segmentation  
- 🧠 Disease: Multiple Sclerosis (MS)  
- 🏗 Model: 3D UNet  
- 🔬 Approach: Hybrid (FCM + Deep Learning)  
- 📊 Metrics: Dice Score, Accuracy, Recall
